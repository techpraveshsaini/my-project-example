# Wellness Centre

A modern, responsive website for a sample wellness centre. Visitors can explore movement classes and general wellbeing services, learn about the centre, browse FAQs, and find sample contact information.

## Features

- Landing page showcasing movement and health-related offerings
- About, FAQ, and Contact pages
- Responsive layouts and keyboard-accessible navigation
- Mocked content with no live feeds, booking, or form submissions
- Informational health content, not medical advice

## Tech Stack

- Next.js
- React
- TypeScript

## Getting Started

npm run dev
